# Sarah's-ai-cloud-journey
 A Python-based AI data assistant that analyzes sales data from a CSV file.

#Technologies:

Python
pandas
CSV
Git & Github
Microsoft Azure
GitHub
AI/Generative AI

#Current Features:

The application can:

- Load sales data from a CSV file
- Calculate product revenue
- Find the product with the highest revenue
- Find the product with the most units sold
- Calculate total revenue
- Answer multiple questions in one session

#Project Goal

The goal of this project is to build a small cloud-based AI data assistant step by step.
The current version performs the data analysis locally with Python.
Future versions will integrate AI and Microsoft Azure services

#Example Questions

What is the total revenue?
Which product has the highest revenue?
Which product sold the most units?
